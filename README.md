# inno-medical-imaging-qc

**غربالگری اولیه‌ی تصاویر پزشکی**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
کمبود رادیولوژیست در شهرستان‌ها و تأخیر در گزارش.

## محصول
اولویت‌بندی و غربالگری اولیه‌ی تصاویر قفسه‌سینه و شکستگی برای ارجاع سریع‌تر.

## کاربران و ذی‌نفعان
رادیولوژیست، مراکز شهرستان

## قابلیت‌های هدف
- اولویت‌بندی فهرست کار رادیولوژیست
- علامت‌گذاری موارد مشکوک
- کنترل کیفیت تصویر

## داده
تصاویر DICOM بی‌نام‌شده و گزارش رادیولوژیست. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
دستگاه پزشکی نرم‌افزاری؛ نیاز به مجوز و اعتبارسنجی بالینی؛ فقط کمکی است.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_imaging_qc generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_imaging_qc validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_imaging_qc demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
کنترل کیفیت (تاری، نویز، کنتراست، برش آناتومی) و امتیاز مشکوک با اختلاف گوسی ماسک‌شده؛ `worklist` (بازآفرینی جدا از ترتیب خوانش).
