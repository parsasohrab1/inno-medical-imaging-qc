# شواهد بلوغ فناوری (TRL) — inno-medical-imaging-qc

**ادعا: TRL 4** (اعتبارسنجی اجزا در محیط آزمایشگاهی). **TRL 5 ادعا نمی‌شود.**

## شواهد
| سطح | شاهد |
|---|---|
| TRL 2 | مفهوم و معیار موفقیت در README و جدول زیر تعریف شده است. |
| TRL 3 | اثبات مفهوم روی داده‌ی مصنوعی: `src/inno_medical_imaging_qc/core.py`، تولیدکننده‌ی داده‌ی قطعی (`generate`). |
| TRL 4 | اجزا (داده → مدل/قواعد → هشدار/خروجی) با تست واحد و معیارهای پذیرش خودکار روی ۳ seed مستقل؛ CI در `.github/workflows/ci.yml`. |

## معیارهای پذیرش TRL 4
| معیار | شرط |
|---|---|
| defective images flagged by QC | >= 0.9 |
| good images wrongly rejected by QC | <= 0.1 |
| ROC AUC of suspicion score (QC-passed images) | >= 0.85 |
| share of lesion images within the top 25% of the read order | >= 0.9 |

نتایج اجرا: [VALIDATION.md](VALIDATION.md) (بازتولید: `python -m inno_medical_imaging_qc validate`).

## آنچه پیاده‌سازی شده
کنترل کیفیت (تاری، نویز، کنتراست، برش آناتومی) و امتیاز مشکوک با اختلاف گوسی ماسک‌شده؛ `worklist` (بازآفرینی جدا از ترتیب خوانش).

## فرض‌های داده‌ی مصنوعی و محدودیت‌ها
تصاویر ۶۴×۶۴ فانتوم مصنوعی با لکه‌ی گوسی؛ هیچ تصویر پزشکی واقعی یا شبکه‌ی عصبی استفاده نشده؛ این ابزار تشخیص بالینی نیست.

عملکرد روی داده‌ی مصنوعی تضمین‌کننده‌ی عملکرد روی داده‌ی واقعی نیست. خروجی‌ها پشتیبان تصمیم‌اند و جایگزین قضاوت بالینی/کارشناسی نیستند.

## لازمه‌های رسیدن به TRL 5
تصاویر DICOM واقعی بی‌نام‌شده با برچسب رادیولوژیست، مدل یادگیری عمیق، مجوز نظارتی (SaMD) و ارزیابی بالینی.
