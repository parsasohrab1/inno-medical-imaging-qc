# کارت داده — inno-medical-imaging-qc

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_imaging_qc generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** تصاویر ۶۴×۶۴ فانتوم مصنوعی با لکه‌ی گوسی؛ هیچ تصویر پزشکی واقعی یا شبکه‌ی عصبی استفاده نشده؛ این ابزار تشخیص بالینی نیست.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
